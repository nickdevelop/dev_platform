# 平台设置中心需求梳理

本文记录平台设置中心目前已确认的产品需求与暂不纳入的范围。本文只描述功能需求，不规定技术实现方案或实施顺序。

## 1. 设置中心范围

平台设置中心当前包含：

- 外观设置
- 模型管理
- Agent 管理

当前明确暂不纳入：

- 工作区授权根目录管理；项目可在任意目录创建，不再依赖授权目录列表。
- 独立的平台诊断功能；Agent 检测与诊断信息属于 Agent 管理。
- 网页安全设置，例如密码修改；此项暂缓，需求尚未确定。

平台现有登录、密码保护和操作系统文件权限等行为不因上述范围调整而自动改变。

## 2. 外观设置

### 2.1 配置内容

- **主题配色**：提供若干预设主题色。每个预设定义完整界面配色，包括背景、文字、边框、按钮等，不只是强调色。
- **字体**：提供若干预设字体，并支持自定义 Google Fonts 字体。
- **字号**：字号以像素为单位设置。
- **界面密度**：提供紧凑、标准、宽松三档。

### 2.2 保存与生效

- 配置保存在平台后台，作为单人使用平台的共享配置。
- 用户修改后立即保存并应用到当前页面。
- 其他已经打开的页面不要求实时同步；刷新页面后应用新配置。

### 2.3 暂未指定

主题预设的数量与具体配色、字体预设清单、字号可选范围和步进尚未确定。

## 3. 模型管理

### 3.1 模型服务

- 支持配置多个独立的模型服务。
- 服务使用 OpenAI API 兼容接口；API 地址由用户自定义填写，首期不限定为平台内置的指定服务商。
- API Key 可以留空，以支持无需鉴权的兼容服务。
- 服务支持编辑、停用和删除。
- 编辑服务时，API Key 输入框留空表示保留已保存的 Key；填写新值表示替换原 Key。
- 删除服务时，其下所有模型一并删除。
- 停用服务后，该服务下的模型均不可使用；重新启用后恢复可用性。

### 3.2 模型列表与维护

- 支持从服务自动获取模型列表；获取结果只用于用户浏览和勾选，勾选后才将模型添加到平台模型列表。
- 支持手动添加模型。
- 添加后的模型信息允许用户编辑，包括模型 ID。
- 模型支持停用和删除。停用模型不可使用；重新启用后恢复可用。
- 模型信息至少包括：
  - 模型 ID
  - 模型名称
  - 文本输入能力
  - 图片输入能力
  - 工具调用能力
  - 上下文大小
  - 输出大小
- 上下文大小和输出大小以 token 数量填写。

### 3.3 模型测试

- 提供模型级测试，不提供单独的服务连接测试。
- 测试针对某个模型发起简单文本请求，验证该模型能否正常调用。
- 首期不通过该测试验证图片输入或工具调用能力。
- 测试使用表单当前配置，包括尚未保存的服务配置和模型配置；测试本身不应隐式保存配置。

### 3.4 暂不纳入

- Agent 如何读取或转换平台模型配置，不属于本次模型管理需求范围。

## 4. Agent 管理

### 4.1 管理对象与检测

- 首期管理 OpenCode 和 Pi Agent 两种 Agent。
- 系统自动检测 Agent 是否存在及其访问路径。
- 若自动检测未发现 Agent，用户可以手动填写对应路径。
- 自动检测到 Agent 后，不提供手动修改该路径的需求。
- 提供检测操作，并显示检测是否成功；检测成功时显示对应版本。

### 4.2 启用状态与项目会话

- 用户可在平台级 Agent 管理界面启用或停用某种 Agent。
- 只有已启用的 Agent 才能在项目中选择并用于创建新会话。
- 停用 Agent 只禁止新建会话；已有会话和已有实例继续可用，不因停用而自动停止或失效。

### 4.3 诊断归属

- Agent 存在检测、路径检测结果和版本信息集中在 Agent 管理中。
- 后端诊断在 Agent 卡片内以可折叠详情展示：异常默认展开，正常默认折叠。
- 项目设置不再展示任何后端诊断或 machine service 提示。
- 不单独建设平台诊断功能；数据库、数据目录等非 Agent 平台诊断当前不在范围内。

### 4.4 Agent 模型清单

- 每个声明模型选择能力的 Agent 展示其模型清单。
- 模型清单由平台持久化保存，默认读取数据库快照，不调用 Agent。
- 只有用户点击“刷新”时，平台才调用 Agent 获取当前模型并原子替换快照。
- 不做定时刷新、后台轮询或自动刷新。
- 不提供项目级模型清单；不考虑项目目录级模型配置差异。
- Agent 模型是 Agent 的只读快照，不是平台模型配置；平台「模型」设置中的 OpenAI 兼容模型服务保持独立。
- 刷新失败时保留上一次成功快照；从未刷新时显示“尚未同步”。

## 5. 工作区管理调整

- 移除授权工作区根目录列表及其网页管理功能。
- 创建项目不再要求项目路径位于预先授权的目录列表下；可以在任意目录创建项目。
- “任意目录”受平台进程本身的操作系统文件权限约束。

## 6. 暂缓与不在范围内

- 安全设置（例如网页修改平台密码）：暂缓，当前没有确定需求。
- 独立平台诊断：暂不做，Agent 相关检测并入 Agent 管理。
- Agent 对平台统一模型配置的消费方式：暂不讨论。
